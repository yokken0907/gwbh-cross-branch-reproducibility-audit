# Terminology guide for external readers

This repository preserves machine-readable workflow identifiers for provenance. They are not intended to carry ordinary-language scientific meaning by themselves.

- **Project Master / branch Master**: an immutable archived evidence container. `Master` is an archival role, not a scientific result category.
- **NO_GO / HOLD**: a prespecified workflow stop or status because a required gate was not satisfied. These labels are **not** evidence that a physical effect is absent.
- **RUNxx / Uxx / Pxx / Mxx / Lxx / Dxx**: technical identifiers retained so public text can be traced to frozen contracts, variables, and runs.
- **RESULTS_FOR_REVIEW**: an archival filename convention for reproducibility review. It does **not** imply journal peer review.
- **PARTIAL_STRUCTURAL / IDENTITY_ONLY / BLOCKED_PUBLIC_ASSET / BLOCKED_SCHEMA / DIRECT_NUMERIC**: frozen cross-branch link-class identifiers. In plain language they mean, respectively: a structural relation without exact numerical alignment; identity alignment only; blocked by missing/inadequate public assets; blocked by schema ambiguity; and direct compatible numerical transfer.
- **Historical `ERRATUM` label**: some frozen U03 machine-readable files use this internal word. It does **not** denote an official LVK erratum. The publication-level statement is that a released notebook description and released table semantics were inconsistent.

## U03 / XR01 publication wording

The publication-facing interpretation is a **within-product summary-to-full-posterior rank association**. Predictor and response are derived from the same released parameter-estimation products within each event and share scale information. The results therefore do not establish independent external predictive performance, waveform-model truth or superiority, causal systematics, or physics beyond the audited frames.

## Version 1.2 publication wording

Publication-facing text uses **within-product rank association** and **disjoint-cohort recurrence** for U03/XR01. Historical machine-readable labels containing `CALIBRATION` or `TRANSPORT` are preserved as provenance identifiers and should not be read as claims of external predictive calibration or strict transportability.
