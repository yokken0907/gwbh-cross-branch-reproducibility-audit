# Project-level forbidden claims

- **F01** — The eight branches form a proven end-to-end numerical or causal chain.
- **F02** — A downstream difference is caused by any particular upstream branch merely because the branches are structurally adjacent.
- **F03** — B03 NO_GO_PUBLIC_ASSETS_INSUFFICIENT demonstrates that selection/injection effects are absent, negligible or irrelevant.
- **F04** — B04 HOLD_PRIMARY_SCHEMA_UNRESOLVED demonstrates that remnant/ringdown dependence is absent or physically null.
- **F05** — B07 FINAL_CLOSED_NO_REPLICATION_TEST_EXECUTED constitutes either successful replication or failed replication.
- **F06** — B08 determines the true H0, identifies a uniquely biased route, or resolves the Hubble tension.
- **F07** — Edge counts or layer order rank the scientific importance, reliability or correctness of branches.
- **F08** — Release/frame mismatches may be ignored because event or topic names overlap.
- **F09** — The project discovers new fundamental black-hole physics solely from the integrated dependency map.
- **F10** — Project closure means future public releases cannot justify reopening blocked or partial bridges.
