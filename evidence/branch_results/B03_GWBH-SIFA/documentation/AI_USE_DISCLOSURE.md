# AI USE DISCLOSURE

This audit workflow and master package were developed through intensive human–AI collaboration. AI assistance was used for code generation, contract / stopping-rule formulation, archive assembly, integrity checks, source and provenance triage, independent re-checking, and documentation synthesis. The workflow deliberately preserves machine-checkable manifests, hashes, frozen inputs, review artifacts, and bounded claims so that the AI-assisted reasoning does not substitute for traceable evidence.

The package does not treat AI output as an authoritative scientific source. Scientific and provenance claims are restricted to what the frozen artifacts and audit outputs support.
