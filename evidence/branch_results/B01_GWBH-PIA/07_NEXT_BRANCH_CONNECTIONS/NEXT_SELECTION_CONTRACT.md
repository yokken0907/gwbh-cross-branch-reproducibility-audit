# Next-Branch Selection Contract

The first branch is closed before a new branch begins.

The preferred next branch is population-inference propagation because it is the nearest downstream consequence of the measured event-level mass and spin posterior dependence.

The next branch must begin with public-data feasibility and must not assume that event-level dependence necessarily changes population conclusions.

Fallback: remnant/ringdown propagation, then controlled analysis-chain ablation where public one-variable-at-a-time comparisons are possible.
