# Standard Research Cycle

1. Define a narrow audit target.
2. Establish public-data feasibility.
3. Freeze metrics, cohorts, outcomes, thresholds, and stopping rules.
4. Run the primary audit without changing the contract.
5. Perform sensitivity and provenance audits.
6. Close the scientific branch.
7. Generate a master reference package.
8. Select the next branch from unresolved downstream consequences.
