# GWBH-PIA Master Reference Package v1.0.0

This package consolidates the authoritative RUN01–RUN31 result packages and the first-branch scientific closure into a directly reusable research asset.

It contains no raw HDF5 files, strain data, virtual environments, or temporary caches. Public-data provenance and checksums remain inside the authoritative nested run packages.

The supported finding is an audit and screening result for released analysis-chain dependence. It is not a pure waveform-error measurement, a model ranking, or a black-hole new-physics claim.
