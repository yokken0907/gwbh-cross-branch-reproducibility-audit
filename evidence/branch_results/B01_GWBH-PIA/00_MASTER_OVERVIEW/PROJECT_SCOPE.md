# Project Scope

The project audited how released binary-black-hole parameter inferences vary across public data releases and across multiple public analyses within a fixed release.

It proceeded from feasibility through posterior-distance calibration, separately frozen holdout confirmations, catalog screening, targeted direct audits, boundary audits, and scientific closure.

It did not reconstruct detector strain, perform new parameter estimation from raw strain, identify a preferred waveform model, or infer new black-hole physics.
