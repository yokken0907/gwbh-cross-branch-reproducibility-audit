## Applied stopping rule

The frozen Phase 6 rule classifies the primary result as complete only if all 22 pairs resolve, partial if at least one resolves, and `HOLD_PRIMARY_SCHEMA_UNRESOLVED` if zero resolve. Schema and quality gates precede numerical access; missing support cannot be imputed.

## Why RUN03 is not authorized

A reader repair can change parsing behavior but cannot create the common declared support required by the already-frozen contract. Running the same archive again would either reproduce the HOLD or require an unauthorized retrospective substitution. It would not be a valid continuation of the confirmatory design.

## Reopening condition

Reopen only when new official, public, production-linked evidence can directly establish the endpoint support needed by P02 without inferring it from observed samples or silently changing the frozen contract. Any reopening is a new post-closure update with new versioning and a new pre-value contract. It must cite this v1.0.0 master unchanged.
