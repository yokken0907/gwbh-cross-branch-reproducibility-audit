# KNOWN LIMITATIONS

- The closure is bounded to the exact frozen GWTC-4.0 pyRing archive identity and recorded public-source chain.
- Raw `.dat`, raw config, and the 1.9 GB source archive are intentionally not retained in result packages.
- RUN02 preserves declaration counts, key names, sections, line numbers, bounded target-like values, and hashes, but not full raw config text.
- P02 common declared support was not established. No support was imputed from software defaults or sample extrema.
- RUN01's 22 `config_equal_except_mode=true` records are invalid as equality evidence and are superseded by RUN02's `NOT_EVALUATED` correction ledger.
- A master-only multiset hash crosscheck found matching non-`kerrmodes` declaration records for all 22 pairs, but it is explicitly non-adjudicative and cannot replace the missing P02 support gate.
- The independent reviews are artifact-level recomputations within this AI-assisted project, not an external institutional replication or peer review.
- No numerical scientific result was produced; absence of a result is an intended stopping-rule outcome, not evidence for a null physical effect.
- This package does not use GWTC-5 run-level content.
